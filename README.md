# Batie

**Batie** (ባቲ) is a dish to feed all, and this site is a dish of links for everyone: free and legal media, Korean learning, and remote work, all in one page.

Every link points to an official source. There are no piracy sites.

## What's inside

- **Free & legal media**: Internet Archive, Project Gutenberg, LibriVox, Tubi, Pluto TV, Kanopy, itch.io, and more.
- **Korean learning & culture**: Talk To Me In Korean, King Sejong Institute, TOPIK, Naver Dictionary, Papago, Anki, Viki.
- **Remote work**: Upwork, Fiverr, ProZ, Remote OK, We Work Remotely, Payoneer, Google Career Certificates, and more.

## Features

- Live search across all links
- Filter chips for each section
- Responsive on phones and desktops
- Light and dark mode that follows the device setting
- One self-contained file with no build step and no dependencies

## Run it

Open `index.html` in any browser, or host it on GitHub Pages, Netlify, or any static host.

## Adding a link

Open `index.html`, find the `D` array in the script, and add `["Name", "https://url", "Short description"]` to the section you want.

## Note

Free tiers and payment options can vary by country. Check each site before relying on it, for example whether Payoneer works for you in Ethiopia.
